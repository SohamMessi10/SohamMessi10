# Soham Chavan

**Fintech**

- [PathForge](https://github.com/SohamMessi10/PathForge): A multithreaded C++20 Monte Carlo option pricer with pybind11 Python bindings, bit-identical for any thread count.
- [VolLens](https://github.com/SohamMessi10/volatility-surface-lab): Arbitrage-checked implied-volatility surfaces — a synthetic Heston market, SVI calibration, and an interactive 3D report.
- [Streaming Risk Monitor](https://github.com/SohamMessi10/streaming-risk-monitor): Rolling risk statistics over an out-of-order, late and duplicated price feed, with z-score alerts scored against ground truth.
- [Market Microstructure Playground](https://github.com/SohamMessi10/market-microstructure-playground): A limit order book and matching engine built from scratch, with exact price-time priority and a step-through replay page.
- [FinSight](https://github.com/SohamMessi10/FinSight_FinancialDataAPI-Dashboard): A market-data platform — FastAPI backend, PostgreSQL storage, a scikit-learn anomaly detector and a Streamlit dashboard, containerized with Docker.

**Data / ML**

- [Docket](https://github.com/AnushaAgarwal27/Docket) — *team project, Cal Hacks 13.0 (2 prizes)*: A caseworker for F-1 students that finds money they're owed, proves every rule with the official clause, and follows up until it's fixed.
- [Evidence Finder](https://github.com/SohamMessi10/evidence-finder): Search a document collection and get ranked passages, each with an exact reference to its source document, section and lines.
- [Inference Bench](https://github.com/SohamMessi10/inference-bench): A benchmark for model servers that shows its working — throughput, latency percentiles and failures under controlled load.
- [EvalRAG](https://github.com/SohamMessi10/Production_RAG_System): Retrieval-augmented Q&A over the FastAPI documentation, built around an evaluation harness.
- [Reproducible Experiment Runner](https://github.com/SohamMessi10/reproducible-experiment-runner) — *in progress*: Runs an experiment from a config file and records what's needed to reproduce and compare it.

**Backend & Tools**

- [Reliable Job Runner](https://github.com/SohamMessi10/reliable-job-runner): A background job queue with retries, leases, fencing tokens and crash recovery, on SQLite.
- [SplitLedger](https://github.com/SohamMessi10/splitledger): A shared-expense tracker for a household — who paid, who it was for, and who owes whom, correct to the cent.
- [Data Contract Inspector](https://github.com/SohamMessi10/data-contract-inspector): A command-line tool that checks a CSV file against an agreed data contract before it enters an analysis or pipeline.
